# Binarios heredados

Estos ficheros binarios vienen del proyecto oficial Cliente @firma (Gobierno de España,
rama `upstream/master`) y se conservan tal cual para no divergir del original. No se
compilan ni se publican desde este repositorio.

OpenSSF Scorecard los marca con el aviso *Binary-Artifacts*. Esos avisos se han
descartado en code scanning como «won't fix», con referencia a este documento.

Si un binario deja de ser necesario o cambia en el proyecto oficial, se revisa aquí.
